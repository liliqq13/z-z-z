# 校卫队值班表

基于 [aiastia/shift-scheduler](https://github.com/aiastia/shift-scheduler) 的 Vue 3 / Pinia 项目改造。上游 README 原文与文件 SHA 保存在 UPSTREAM_README.md、UPSTREAM.json，原始代码保留在 Git 初始提交。上游 README 声明 MIT，未代替上游填写版权信息。

## GitHub Pages 发布

网页已经编译在 `docs/` 目录。打开本仓库 **Settings → Pages**，Source 选择 **Deploy from a branch**，Branch 选择 **main**，目录选择 **/docs**，保存。部署成功后，使用 Pages 页面实际显示的网址。

仓库上传完成不代表 Pages 已开启。国内访问速度和稳定性以实际网络为准。换网址前先在原系统导出 JSON 备份，再在新网址恢复。

开发后运行 `npm run build`，将 `dist/` 内容复制到 `docs/` 提交更新，保留 `docs/.nojekyll`。资料保存在访问者当前浏览器，仓库和网页不包含用户录入的人员、排班、请假资料。

## 使用

仅保留“排班表、人员、设置”三个入口，排班表支持表格和月历切换。

- 添加人员时选择“能开车 / 不能开车”。旧名单未知的驾驶能力保持“待确认”。
- 巡逻车和办公室统一 20:00—22:00；巡逻车可安排 1 人或 2 人，至少一人能开车。单人巡逻必须能开车。
- “活动值班”和“其他值班”可自行设置时间、人数、日期。只在指定日期参与自动排班，也可点击表格或日历直接添加，保存人员后会将该日期加入该岗位的日期名单。
- “按周排班”按周一至周日生成一周，可快速选择本周、下周、前后周。默认每人每周最多 2 次，设置中可调整，0 表示不限。所有岗位共用次数上限。
- 自动排班优先本周次数较少的人员，兼顾历史负担、岗位分布、周末和上周同日轮换。办公室优先安排不会开车的人；这些人不可用时才使用其他符合规则的人员。
- 手动安排、已结束班次和人工修正记录会保留；人手或司机不足时显示缺口，不悄悄突破次数上限。历史已保留的超额安排不会被删除。
- 点击单元格或日历日期可安排人员、修改值班记录，也能查看自动计入状态。

## 删除人员

“人员”页每行和编辑人员弹窗均提供删除按钮，手机端可点击姓名进入编辑后删除。所有人员均可删除，包括已停用或有历史排班的人员。确认弹窗显示关联排班、值班状态和请假区间数量，提供导出备份入口。确认后清除该人员及其关联排班、值班记录和请假区间，其他人员、岗位及当日人数设置保留，空缺在排班表中显示。删除不能直接撤销，可从删除前的 JSON 备份恢复。仅停止排班时，可在编辑人员的更多选项中取消“参与排班”。

## 请假管理

在“人员”页登记请假，选择人员、开始日期、结束日期和选填备注，起止当天均包含。每人可保存多个不重叠区间，支持修改、取消和查看历史。自动及手动排班均检查请假区间，跨夜班次只要与请假日重叠也会避开。

已排但未人工登记的班次会派生为请假状态，计入时长为零；重新生成排班或在原单元格补人时，原请假记录保留。人工到岗及完成记录保持优先，页面提示与请假冲突，需人工核对。取消或缩短请假后人员恢复排班资格，已标为请假的原班次保留为历史记录，避免补人后重复占岗；仍可逐条修改。

请假区间随人员资料保存，旧数据自动补空列表。JSON 备份包含全部请假资料，Excel 附“请假记录”工作表。

## 自动计入与人工修改

时间按 Asia/Shanghai 计算。没有人工登记的班次，到计划结束时自动按计划开始、结束时间计入，标记“自动计入”。支持跨夜、活动自定义时段和跨月统计；未结束的班次不会提前计入。

人工输入的时长、请假、缺勤或值班中状态始终优先，不会被自动计入覆盖。可修改自动记录，也可移除人工修改后恢复自动计算。按计划计入的记录不是定位或现场签到结果。

自动结果由已保存的排班与当前时间计算。网页关闭时没有后台进程，下次打开、刷新或导出会补算；页面打开时定时刷新显示。全部原始排班和人工修正都随 JSON 备份保存。

## 公平性与规则

规则轮转最多尝试 16 次，优先减少人数和司机缺口，再均衡分配；不能证明全局最优或不可行。先为每辆车预留司机，再优先安排办公室，最后补充随车和其他岗位，避免把稀缺司机用完。

检查人员不可值班日期、时间重叠、休息间隔、每周时长、每周次数和每天最多一个岗位。自然周在跨月时连续计算，周一重新计算周次数。跨夜工时按上海时间在周日/周一边界拆分。跨月班次按排班开始日期计入月度统计。

已有版本升级时改名并补充新规则。原早班/白班改为活动值班，晚班/夜班改为其他值班；历史人工记录和时间快照保留，未来未登记的巡逻、办公室更新为 20:00—22:00。

## 导出和存储

Excel 第一张工作表是所有岗位合并的排班表，附值班记录（区分自动与人工来源）、时长统计、驾驶能力名单和请假记录。右上角“更多”提供时长统计及 JSON 备份恢复。

单人操作，资料保存在当前浏览器 localStorage（duty_roster_v2），无跨设备同步。清理站点数据会清除记录，换设备前请导出备份；保存失败会明确提示。

## 开发

Node.js 22.12+。npm install 后执行 npm run dev；npm run build 生成静态目录 dist/。npm test 验证排班、驾驶能力、周上限、公平性、办公室优先级、活动日期、自定义时段、上海时间自动计入、人工覆盖、旧数据迁移、请假区间、取消补班冲突和 Excel 内容。

默认不添加任何人员或实际记录。浏览器 QA 仅使用预览域名，校验后已恢复为空白名单。
